## 6. Choices made inside the task, and limits (disclosed)

- The file rule `catalog/assignments/<pin id>.json`, the format `agent-assignment/v1` and the catalog repository
  id `ai-engineering-harness` are this leaf's; A-01.1 may supersede them with its Gitea catalog.

  the stage (a binding may approve several profiles with one pin; the profile's pin and admission bind what the
  create carries). For D1 a test holds them equal.
- The `resolve` command reads the request's repository from the given `--project`; that it is a clone of
  `aieh-demo/aieh-d1-demo` is not checked (a wrong project fails on the Work or the accepted design).
- The candidate says version 1: correct only if no promotion was recorded live before; planning reads `status`
  first.
