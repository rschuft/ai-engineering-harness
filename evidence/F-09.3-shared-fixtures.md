## 11. Findings

Classified per the fix-forward rule.

- **Introduced by this leaf, fixed before commit:** a shell heredoc turned a `\x00` escape in
  the fixture's digest into a NUL byte (rewritten with a script, checked); the first runner
  seam bound a class-attribute function as a method (now read through `type(self)`); the first
  in-process runner refused a non-fake argv, which would have hidden the real launch failure of
  a missing command (it now launches any other argv); the first `GoldenRepository` checks went
  through the fixture's own git helper (they now ask git directly).
- **Exposed by this leaf, fixed forward:**
  - `1366090`: the fixture's `git add` failed past 259 characters under a 123-character TEMP
    (section 7).
  - `1c44d91`: the guest tests' `shutil.rmtree(tmp, True)` could not delete git's read-only
