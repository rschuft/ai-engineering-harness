## Findings

- A, B, C (above): introduced-by `622bd75`, exposed-by F-10.4; repaired forward in `fb9b25c`.
- **The exchange bundle is three times larger and the checkout push 2.4x slower** than git's
  (no deltas in Dulwich's pack). Exposed-by F-10.4. Recorded, not tuned. A larger repository's
  bundle reaches `exchange.push.max_bytes` (256 MiB) sooner than git's would.
- **The serial median (149.6 s, Git Bash) is at the F-09 gate's edge** (at most 150 s, evaluated
  at F-10.5). Exposed-by F-10.4.
- **`profiles/strong-windows-qemu-whpx/profile.json` still describes the push as built with git
  and checked with `git bundle verify`** (`lifecycle.bindings`, "exchange push"). Introduced-by
  F-10.4 (the description is now stale); `profiles/` is outside this leaf's paths, and a profile
  change moves the profile revision create records.
- **The checkout changed during the leaf**: `883905c` (the bootstrap log) was committed, and two
  tracked files (`decisions/0007-…`, `evidence/E-01.4.3-…`) were modified, outside this leaf.
  Unrelated-but-detected; untouched and unstaged here.
- Tests of a non-repository path (`NOT_A_WORK_TREE`, `CHECKOUT_UNLISTED`) let the module's
  discovery check `.git` at each directory up to the drive root, as git's own discovery does.
  Unrelated-but-detected (the F-10.2 suite does the same).
