Both failures assert that no path above the configured ceiling is touched during discovery. On Linux the test's
observation lists the ancestors of the guest's temporary directory (`/srv`, `/srv/scratch`, `/srv/scratch/agent`,
`/srv/scratch/agent/f105`, `/srv/scratch/agent/f105/tmp` and the test's own corpus directory), each recorded
twice. **Observed:** these paths were recorded by the test's observation on Linux and not on Windows.
**Not yet established:** which call records them (product code or the test's own observation), and whether the
contract of decision 0014 is breached or the test over-reaches on POSIX. A plausible hypothesis, unverified: path
canonicalization on POSIX (`posixpath.realpath`) inspects each ancestor component, where Windows resolves through
the final path handle. Classified exposed-by (the Linux qualification exposes a platform difference); dispatched
for diagnosis.
