## 2. The change and its bearing on the suite

- **`test_repository_access.py`.** Only the `Ceilings` class changed, plus the imports `contextlib` and `errno`.
  The diff is 135 lines added and 17 removed.
  - The spy pauses recording only while `os.path.realpath` runs, so canonicalization's own lookups are not
    recorded. Every other probe is recorded: `os.path.isfile/isdir/exists/islink`,
    `os.stat/lstat/scandir/listdir` and `open`.
  - A probe of a path outside the corpus's temporary root is recorded and answered "absent" without reaching
    the disk.
  - Three tests were added:
    - `test_no_path_above_the_ceiling_is_touched_under_posix_canonicalization`;
    - `test_a_ceiling_between_the_start_and_a_repository_hides_it_under_posix_canonicalization`;
    - `test_without_a_ceiling_the_search_probes_up_to_the_file_systems_root`, the positive control.
  - The forced-POSIX tests replace `os.path.realpath` with a port of the posixpath component loop. Under the spy,
    `os.lstat` answers components above the temporary root with a synthetic directory, so nothing above the
    root is read.
  - On Linux, the two original tests now exercise the real `posixpath.realpath` under the guard. This is exactly
    the case that failed under revision 3.
  - No other test changed. No test gained a launch, a temporary directory or a socket.
- **`repository_access.py`.** Only the `discover` docstring changed: 1 line removed and 4 added. An AST
  comparison with docstrings blanked is identical at both commits, so no code changed. `tools/guest.py`, which
  loads this module on the host, is unaffected for the same reason.
