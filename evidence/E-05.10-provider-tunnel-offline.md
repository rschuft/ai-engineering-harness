## Adopt or own: owned

An established proxy would be adopted if one met every clause at a pin on this Windows host's loopback (CONNECT
only, an exact host:port allowlist, IP literals refused, the tunnelled ClientHello's server name checked without
terminating TLS, no credential, target, decision and byte-count logging only). A documentation-only survey (no
install, nothing pinned or run) found none: Squid peeks at the SNI and splices, but its `ssl_bump` port must be
configured with a certificate and key even when it never bumps, and it has no maintained native Windows release;
mitmproxy reads the SNI for passthrough but generates and holds a CA key; Envoy (`tls_inspector`) and HAProxy
(`req.ssl_sni`) read the SNI of direct TLS, not inside a CONNECT, and have no supported Windows build; nginx needs a
third-party CONNECT module and its `ssl_preread` has the same limit; Tinyproxy, Privoxy and Caddy's `forwardproxy`
filter the CONNECT target and never read the ClientHello. The tunnel is therefore owned, minimal and standard
library only.

### 5. From a job: the tunnel's admission, and the name lookup

1. Start the sampler (independent of the tunnel's log; gap 2), a read-only PowerShell loop in a second background
   command, recording every TCP row to remote port 443 **of any owner** (TIME_WAIT rows carry pid 0) and every
   row of the tunnel's pid, each the first time it is seen, until `OUT\09-probe.done` exists:
   ```
   $p = <tunnel pid>; $seen = @{}
   while (-not (Test-Path OUT\09-probe.done)) {
     @(Get-NetTCPConnection -RemotePort 443 -ErrorAction SilentlyContinue) +
     @(Get-NetTCPConnection -OwningProcess $p -ErrorAction SilentlyContinue) |
       ForEach-Object { $k = "$($_.OwningProcess) $($_.LocalAddress):$($_.LocalPort)>$($_.RemoteAddress):$($_.RemotePort) $($_.State)"
                        if (-not $seen[$k]) { $seen[$k] = 1; "$((Get-Date).ToUniversalTime().ToString('o')) $k" } }
   ```
