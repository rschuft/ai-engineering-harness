## Determinations (with citations)

### Switch spelling: `tRuE` for both switches

Sources, downloaded read-only to a scratch directory outside the checkout and checked against the npm registry's
`dist.integrity` (sha512): `@agentclientprotocol/claude-agent-acp` 0.63.0 (its `package.json` and `dist/index.js`
sha256 also equal the image record, [S-03.3 image adapter check](S-03.3-image-adapter-check.md) section 4.1);
`@anthropic-ai/claude-code` 2.1.220, a wrapper whose CLI is its platform package
`@anthropic-ai/claude-code-linux-x64` 2.1.220 (binary `claude`, sha256
`674f61f20ff306f3100cf9200e4c36c4b70278b5bef2884549819b942a89c863`). No repository record pins a CLI digest; the
binary's identity with the image's is E-05.11's to show. Byte offsets are into that binary:

- `CLAUDE_CODE_PROXY_RESOLVES_HOSTS` is read only as `Z.CLAUDE_CODE_PROXY_RESOLVES_HOSTS` (@248833875), whose accessor
  is `Uph=De.bool()` (@247596689); `De.bool` transforms by `Yt` (@247422263), and
  `function Yt(e){... String(e).toLowerCase().trim(); return ["1","true","yes","on"].includes(t)}` (@246889477,
  identified as the same bundle scope by proximity, an inference). Documentation (code.claude.com/docs/en/env-vars):
  "Set to `1` to allow the proxy to perform DNS resolution".
- `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC` is read raw, `if(process.env.CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC)`
  (@247437828, @247438137, @247438269): any non-empty value. Its declared accessor is the same bool (@247568902).
  Documentation: "Set to any non-empty value, such as `1`".
- `tRuE` is accepted by every reader of both, is neither `1` nor `true`, and occurs 0 times in the 275 MB binary.
- **Masking is case-sensitive** (the independent review, on the openhands-sdk 1.60.1 wheel whose sha256
  `f6efa8f8428ccc8abebbcf4c424bf3008a66a46f9f2340d37b3b306fcb45eb6b` is the lock's):
  `conversation/secret_registry.py:321` `masked_text.replace(value, "<secret-hidden>")` and `:339-341` an unflagged
  `re.compile` of the escaped values. So `tRuE` masks only `tRuE`, never `true`, `True` or `TRUE`.

### The token's shape

No source states the exact shape of the value `claude setup-token` prints. The documentation calls it "OAuth access
token for claude.ai authentication" (env-vars) and shows `your-token` (authentication, "Generate a long-lived
token"); the pinned CLI prints the token exchange's `accessToken` unchecked (@260600433). What the sources state is
the provider's credential grammar: the CLI's `^sk-ant-[a-z0-9]+-` (@250661125) and its redactor
`\bsk-ant-[A-Za-z0-9_-]{8,}` (@250606913); the documentation shows OAuth access tokens as `sk-ant-oat01-...`
(routine trigger tokens; environment keys), session tokens as `sk-ant-cc-` and `sk-ant-si-`, API keys as
`sk-ant-api03-...`. Admitted: `sk-ant-`, a lower-case label of letters and digits, `-`, then only
`[A-Za-z0-9_-]`, 40 to 512 characters, no whitespace; the labels `api*`, `admin*`, `sid*`, `cc` and `si` refused.
Not narrowed to `oat01`.

### The native create's closed world, and the fields the pinned SDK forwards (review B1)

From openhands-sdk 1.60.1 (`settings/model.py` `ACPAgentSettings.create_agent`, lines 2142-2175;
`agent/acp_agent.py` `_start_acp_server`, `_isolate_acp_data_dir`, `_materialise_file_secrets`,
`_materialize_skills`):

| Field | Where the SDK sends it | Admitted |
|---|---|---|
| request `secrets` | the secret registry, injected into the ACP process environment | exactly the four StaticSecrets |
| `acp_command`, `acp_args` | the subprocess command line | `["claude-agent-acp"]`; `[]` |
| `acp_server` | the provider's identity | `claude-code` |
| `acp_model`, `acp_session_mode` | the ACP protocol | one model name (required); null |
| `acp_prompt_timeout`, `acp_startup_timeout` | harness timeouts | refused |
| `acp_isolate_data_dir` | `CLAUDE_CONFIG_DIR` set to `<persistence>/acp/claude-code` | true |
| `acp_file_secrets` | files under `<persistence>/acp/<subdir>` and an environment variable pointing at them | absent or `[]` |
| `agent_context` | `secrets` seeded into the registry (so the environment); `skills` written under the persistence directory | absent or null |
| `mcp_config` | forwarded to the ACP session | `{}` |
| `agent_kind`; `schema_version`, `verification` | not forwarded | `acp`; refused |
| other request fields (`agent_launch_additions`, `plugins`, `hook_config`, `agent_definitions`, `client_tools`, `tool_module_qualnames`, `agent_profile_id`, `initial_message`, `prompt`, `worktree`, ...) | | refused (`NATIVE_BODY_FIELD_FORBIDDEN`; the D1 stage's own body allowlist refuses first) |

(`CODEX_AUTH_JSON`, `KIMI_CODE_CONFIG_TOML`, `GOOGLE_APPLICATION_CREDENTIALS_JSON`, `PI_AUTH_JSON`) that none of the
four admitted names is, so nothing materialises.
