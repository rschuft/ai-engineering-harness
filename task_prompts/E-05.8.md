Offline, with a fake Agent Server: each such provider refusal, cut-off stream and lost path is recorded as an interruption, and every containment, credential or unexpected-egress stop is recorded as non-retryable. The classification is taken from the conversation's recorded status and events and the dispatcher's own records, never from an exit or HTTP status alone. When an attempt's conversation ends, or the attempt is stopped, after an interruption, the dispatcher ends the attempt: the conversation's runtime is stopped and observed stopped, and an end record (attempt, conversation, classification, the surfaced codes and statuses, fingerprints only) is written durably in the integration store; the reservation receipt and the task's Backlog.md and OpenSpec records are kept unchanged, and the interrupted attempt hands no result to the result path. Ending an interrupted attempt is repeat-safe: repeating it, or resuming it after a crash partway through (after the runtime stopped, after the end record was written), converges on one end record, with no duplicate record, shown by tests that repeat each step. A new attempt for the same task (the next ordinal on the same work item, design revision and stage) is admitted only once the earlier attempt's end record shows an interruption and its conversation stopped, and it gets a new conversation. A provider authentication refusal ends the attempt like any interruption and needs the Owner: a new attempt after one is admitted only once the engineering manager has recorded its cause and, where the provider refused the token, the Owner has entered a new one (OA-31 (e)), never by an automatic retry. A new attempt is refused with a stable code while the earlier attempt has no end record or its conversation still runs, after an authentication refusal whose cause is not recorded, and after a non-retryable end, which stops the leaf as a security stop. The token is never delivered again to an existing conversation or attempt. No record, report or log carries the native token, only its fingerprint.
