Map each stage to its bot role token: the stage's standing bot credential, borrowed only for a confirmed attempt of that stage, used only in the dispatcher's bounded attempt context and never inside a container, and released when the operation ends (releasing the in-memory reference is not Gitea revocation); records carry fingerprints only; the standing credential is rotated or revoked only on defined security and lifecycle triggers under the existing administrative authority (decision 0007 points 4 and 5, amendment 1), because Gitea 28.3.0 gives the dispatcher no replacement mechanism; the per-attempt inference token stays revoked at attempt end (decision 0015). EXACT ACCEPTANCE EVIDENCE
On a disposable guest: the key file's owner, group and mode equal the profile's declaration and it is readable in the guest only by the login the dispatcher holds the key of (during bootstrap agent, decision 0013 point 1); a container's read is refused and no container file or environment holds the key's or a role token's fingerprint; a conversation runtime credential minted by the dispatcher is refused on every key-gated management route and admitted only by its conversation's inner server; each stage uses exactly its mapped bot; records carry fingerprints only. Offline tests against Gitea fakes demonstrate: a confirmed attempt cannot acquire another stage's credential; two sequential attempts of one stage succeed with the authorized standing credential; concurrent attempts of one stage cannot invalidate one another (releasing one leaves the other's credential usable, and nothing revokes); an actually revoked Gitea credential fails closed until the administrator-managed lifecycle restores it (rotate, or retire then provision, replacing the entry), after which delivery works again; no stage credential or its raw value reaches a guest, an agent environment, a container, a conversation, a conversation record or the UI, through the Agent Server client or through the live transport's request path. A live administrative revocation is not part of this proof: it is optional and its own Owner act.
